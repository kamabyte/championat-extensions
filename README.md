# Championat Tweaks

Расширение для Chrome, которое добавляет удобства в турнирные таблицы на [championat.com](https://www.championat.com).

## Что умеет

- **Таблица при равном числе игр.** Переключатель «При равном числе игр» показывает, как выглядела бы таблица, если бы все команды сыграли одинаковое число матчей. Недостающие матчи засчитываются как победы. Работает для футбола, хоккея, баскетбола и волейбола.
- **Сортировка по любому столбцу.** Нажмите на заголовок столбца: первое нажатие сортирует, второе меняет направление, третье возвращает исходный порядок.
- **Сортировка по разнице шайб или мячей.** В столбцах вида `76-49` нажатия идут по кругу: сначала по забитым, затем по разнице (в заголовке появится `±`), затем исходный порядок.
- **Подсказка с разницей.** Наведите курсор на значение вроде `76-49`, и появится «Разница: +27».

## Установка

1. Скачайте репозиторий: **Code → Download ZIP**, затем распакуйте архив. Или выполните `git clone`.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите **режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите папку с проектом.

После обновления файлов нажмите кнопку обновления на карточке расширения и перезагрузите страницу сайта.
